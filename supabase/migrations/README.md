# Supabase Database Migrations

This folder contains SQL migration files for AVISHKAR-v2 database schema.

### Schema Blueprint (Upcoming Milestones)
- `001_initial_schema.sql` - User profiles, roles, and event config table.
- `002_registrations.sql` - Student registrations, team members, competition mapping.
- `003_payments.sql` - Payment audit logs, receipts metadata, and review states.
- `004_checkin_qr.sql` - QR code hash tokens and campus check-in timestamps.
